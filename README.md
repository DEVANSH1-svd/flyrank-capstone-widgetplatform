# Embeddable Widget & Lead-Capture Platform

A backend platform where customers define embeddable widgets (signup forms, contact forms), install them on any website with one `<script>` tag, and receive visitor submissions that are validated, spam-filtered, enriched with location data, stored, and shown in an owner dashboard.

Built with Python and FastAPI as the FlyRank Internship Backend Track capstone.
